## Learning Script Executer

This repo now includes `Script Executer.js`, a simple bookmarklet-style executer for testing snippets in your own browser session.

### How to use
1. Open `Script Executer.js` and copy all of its contents.
2. Create a browser bookmark and paste the contents as the bookmark URL.
3. Click the bookmark on the page where you want to test code.
4. Paste a JavaScript snippet (or full `javascript:` bookmarklet) into the prompt.

⚠️ Only run scripts you understand and trust.
